Getting Started

The order endpoint accepts service_name, network, offer_id, and recipient_number. All responses are JSON.
Auth Header
x-api-key
Base URL
{{ request.host }}
Format
JSON
Response you will get
{ "status": "success", "message": "API ready" }

Authentication

All requests require an API key sent via headers:
x-api-key: YOUR_API_KEY
Request to send
GET /api/packages.php Headers: x-api-key: YOUR_API_KEY
Response you will get
{ "status": "success", "message": "Successful" }
Sample code (Node.js)
const res = await fetch(`${window.location.origin}/api/packages.php`, { headers: { "x-api-key": "YOUR_API_KEY" } }); console.log(await res.json());

Create Order

POST
Endpoint: /api/send_order.php
Request to send
{ "recipient_number": "0554226398", "service_name": "MTN NORMAL", "network": "MTN", "offer_id": 1 }
Reference / Order ID is generated automatically.
Response you will get
{ "status": 200, "message": "Order recorded successfully", "reference_id": "API0552321442c5ddfe6", "order_id": "ORDER-123456" }
Sample code (Python)
import requests payload = { "recipient_number": "0554226398", "service_name": "MTN NORMAL", "network": "MTN", "offer_id": 1 } r = requests.post( `${window.location.origin}/api/send_order.php`, headers={"x-api-key": "YOUR_API_KEY", "Content-Type": "application/json"}, json=payload, timeout=60 ) print(r.json())
Legacy endpoints (still supported): /api/initiate.php and /api/special.php

Order Status

GET
Status Codes
1 100 Admin wallet is low 2 101 Account out of stock 3 200 Successful 4 500 Internal system error 5 102 Agent not found 6 103 Price not found 7 555 Network not found
Endpoints: /api/response_regular.php or /api/response_big_time.php
Request to send
GET /api/response_regular.php?reference_id=API0552321442c5ddfe6 Headers: x-api-key: YOUR_API_KEY
Response you will get
{ "status": 200, "success": true, "message": "Order found", "data": { "beneficiary": "0554226398", "gig": "1", "network": "MTN", "order_date": "Sunday, January 18, 2026", "order_time": "23:21:44 PM", "price": 4.2, "order_status": "Pending" } }
Sample code (Node.js)
const reference_id = "API0552321442c5ddfe6"; const res = await fetch( `${window.location.origin}/api/response_regular.php?reference_id=${encodeURIComponent(reference_id)}`, { headers: { "x-api-key": "YOUR_API_KEY" } } ); console.log(await res.json());
